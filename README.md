# 🚀 GameOver YouTube High-Speed Streaming API

A high-performance private microservice for YouTube audio/video search, streaming, and caching.
Equipped with native persistent **Hugging Face Storage Buckets (`/data`)** ensuring 100% data persistence across container restarts.

## ⚡ Features
- 🔍 Fast YouTube Search & InnerTube 35-track Smart Vibe Autoplay
- 🎵 Multi-format audio downloads (OPUS 48kHz Studio HD, MP3 320k, M4A AAC, FLAC, WAV)
- 🎬 High-speed video streaming (480p, 720p, 1080p)
- 🗄️ Native Hugging Face Persistent Storage Bucket (`/data/cache` & `/data/controller.sqlite3`)
- 🤖 Built-in Telegram Controller & Logger Bot
- 🛡️ Zero-cookie, 100% YouTube bot block bypass architecture
